# What do we do?

Construye tu trineo, explora la montaña nevada y compite con tus amigos. Versiones de prueba para Windows de 64 bits y Android ARM64.

## Instalar el juego

1. [Descarga el instalador WhatDoWeDo-Setup.exe](https://github.com/xonfirex1996/whatdowedo-releases/releases/latest/download/WhatDoWeDo-Setup.exe).
2. Ejecútalo y sigue los pasos. Incluye el juego completo y crea accesos directos.
3. Abre el juego. No necesitas cuenta de GitHub ni configurar tokens.

Se instala para tu usuario de Windows. La instalación no necesita descargar otros componentes del juego.

## Actualizar

En el menú principal, pulsa el botón de versión de la esquina inferior derecha. Comprueba las novedades, descarga y selecciona **Instalar y reiniciar**. Necesitas conexión a Internet para consultar y descargar actualizaciones.

Tus ajustes y tu personaje se guardan por separado y se conservan en el mismo usuario de Windows. Para jugar en LAN, todos deben tener la misma versión.

Si tu copia antigua no incluye el botón de versión, instala el juego con el instalador una vez y utiliza el nuevo acceso directo.

## Android

Descarga [WhatDoWeDo-Android.apk](https://github.com/xonfirex1996/whatdowedo-releases/releases/latest/download/WhatDoWeDo-Android.apk).
Instálalo encima de la versión anterior para conservar tus ajustes y personaje.
Las copias antiguas sin actualizador necesitan instalar un APK compatible una vez.

Desde el menú, **Versión → Buscar → Descargar → Instalar APK** permite actualizar.
Android pedirá permitir instalaciones desde el juego la primera vez y confirmar
cada instalación. Si cancelas, podrás reintentar con la descarga verificada.

Android requiere un dispositivo ARM64 y Android 7 o posterior. Es una versión de
prueba; el rendimiento y la compatibilidad pueden variar según el teléfono.

## Jugar con amigos por LAN

Actualizad todos a la misma versión. El anfitrión entra en **Jugar → Crear mapa**,
pone un nombre y activa **Abrir en LAN**. Los demás usan **Jugar → Unirme a LAN**
con su IP local y puerto. Conectad los equipos a la misma red y permitid el juego
en el firewall de redes privadas de Windows. Cada jugador tiene su propio trineo.

## Opción portable para Windows

También puedes [descargar el ZIP completo](https://github.com/xonfirex1996/whatdowedo-releases/releases/latest/download/WhatDoWeDo-Windows.zip), extraer todos sus archivos en una carpeta propia y abrir `WhatDoWeDo.exe`. Conserva juntos el ejecutable, el paquete del juego y sus bibliotecas.

[Ver las novedades y todas las descargas](https://github.com/xonfirex1996/whatdowedo-releases/releases/latest).

Este repositorio contiene únicamente descargas, notas y el manifiesto público de actualizaciones. No contiene el código fuente del juego.
