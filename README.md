# What do we do? — Descargas

Versiones de prueba del juego para Windows. Este repositorio contiene únicamente las descargas y las notas de actualización.

## Descargar

Abre [la última versión](https://github.com/xonfirex1996/whatdowedo-releases/releases/latest), descarga `WhatDoWeDo-Windows.zip`, extrae todo su contenido en una carpeta y ejecuta `WhatDoWeDo.exe`.

## Actualizar

En el menú principal, pulsa el botón de versión de la esquina inferior derecha, busca la actualización y selecciona instalar y reiniciar.

Si tu copia antigua todavía no tiene ese botón, descarga y extrae la carpeta nueva completa una vez. Los ajustes y personajes se guardan aparte en AppData.

Para jugar en LAN, todos deben usar la misma versión.
